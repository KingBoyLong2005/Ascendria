# 🕹️ Ascendria

A co-op node-based roguelike game with up to 4 players, built in Unity 6.
Battle your way through floors full of random events, monsters, and bosses!

---

## 📖 Overview

**Ascendria** is a co-op roguelike game inspired by **DEEP ROCK GALATIC**.  
Players progress through a **node-based map** spanning up to 20 floors, facing random events such as:

- 🧟 Monster fights  
- 🛒 Shops  
- 💀 Challenges  
- 👑 Boss rooms  
- ❓ Unknown events

---

## 🎮 Features

- 🧭 Node-based map with procedurally generated paths
- 🔄 20 floors per run (with looping + difficulty scaling)
- 🎲 5 event types: Monster, Shop, Challenge, Boss, Unknown
- 🧑‍🤝‍🧑 Co-op multiplayer (up to 4 players)
- 🕹️ Keyboard + gamepad support
- 🔄 Replayable with different paths every run
- 🖥️ Built with Unity 6 for PC

## 🗂️ Folder Structure

```plaintext
Assets/Game/
├── Art/                # Sprites, VFX, animation controllers
├── Audio/              # Music, SFX
├── Prefabs/            # Rooms, events, player prefabs
├── Scenes/             # MainMenu, GameScene, NodeMap
├── Scripts/            # Gameplay logic scripts
├── ScriptableObject/   # Game data containers
└── UI/                 # UI screens and components
```
